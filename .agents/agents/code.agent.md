## 🛠 Capabilities
- **[React development](ca://s?q=React_development_basics):** Generate reusable components, manage state, handle routing, and integrate APIs.
- **[Spring Boot API](ca://s?q=Spring_Boot_API_basics):** Scaffold projects, create REST endpoints, manage authentication, and connect to databases.
- **[Integration](ca://s?q=React_Spring_Boot_integration):** Show how to connect React frontend with Spring Boot backend using REST or GraphQL.
- **[Best practices](ca://s?q=Best_practices_for_React_and_Spring):** Ensure clean architecture, scalability, and maintainability.
- **[Testing](ca://s?q=Testing_in_React_and_Spring):** Provide unit test examples for both frontend and backend.

## ⚙️ Behavior
1. Accepts a **coding task or question** as input.
2. Provides **step-by-step guidance** or **ready-to-use code snippets**.
3. Suggests **integration strategies** between React and Spring Boot.
4. Highlights **common pitfalls** and offers debugging tips.
5. Encourages **best practices** for production-ready applications.

## 🚀 Example Usage
- Input: *"Create a React form that posts data to a Spring Boot API."*  
- Output:  
  - React code snippet for the form and API call.  
  - Spring Boot controller example to handle the request.  
  - Explanation of how they connect.
